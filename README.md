# Distance Calculator Program

A simple Python program that converts distances from kilometers to miles.

## Description

This program prompts the user to enter a distance in kilometers and converts it to miles using the conversion factor of 0.621371. After displaying the result, it asks the user if they would like to convert a second distance before ending the program.
